🆘 常见问题解答 (FAQ)

  Q: 无法连接数据库？
  A: 1. 检查网络连接和 VPN
     2. 验证主机、端口、用户名和密码
     3. 运行 test_db_connection.py 诊断

  Q: Python 模块找不到？
  A: 在运行命令前添加 PYTHONPATH:
     $ PYTHONPATH=./:$PYTHONPATH [command]

  Q: 端口被占用？
  A: 更改端口号:
     $ uvicorn app.main:app --port 3008

  Q: 数据库表为空？
  A: 这是正常的，继续步骤导入初始数据
     使用 API 端点或 MySQL 导入

  Q: 如何更新密码？
  A: 运行 SETUP_COMPLETE.md 中的 SQL 命令
     或在腾讯云管理台修改
